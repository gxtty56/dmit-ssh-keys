## 为什么 DMIT 要用 SSH 密钥？密码不香吗？

你可能会疑惑：密码用了那么多年，为什么 DMIT 要强推密钥登录？

事情是这样的。一台暴露在公网的 VPS，每天都会收到成千上万次自动化暴力破解请求。那些扫描工具 24 小时不停地试各种常见密码：`123456`、`password`、`admin123`……如果你用弱密码，被攻破只是时间问题。

**SSH 密钥的逻辑完全不一样。** 密钥登录不是"输入一个正确的密码"，而是一对数学上互相关联的密钥：**公钥**（放在服务器上）和**私钥**（只在你自己电脑上）。登录的时候，服务器用公钥出一道"数学题"，只有拿着对应私钥的人才能答对。没有你的私钥文件，暴力破解根本无从下手。

DMIT 默认禁用密码登录，强制使用 SSH 密钥，这是一个负责任的安全策略。习惯了之后你会发现，登录还更快，连密码都不用打了。

## 搞清楚两种密钥方案，别搞混

在开始操作之前，先理清楚 DMIT 的两种密钥获取方式：

**方案 A：DMIT 帮你生成，你下载来用**

购买 VPS 之后，DMIT 后台会生成一对密钥，你需要去下载那个私钥文件（通常是 `.pem` 格式），然后用它登录服务器。这适合懒得折腾的人——开箱即用，省事。

**方案 B：你自己生成密钥对，把公钥上传到 DMIT**

自己在电脑上生成一对密钥，把**公钥**的内容粘贴到 DMIT 账户里。这种方式更灵活——你的私钥从来不经过 DMIT 的服务器，安全性更高，也方便统一管理多台服务器的密钥。

两种方式都可以，选哪个看个人习惯。下面分别讲。

## 方案 A：从 DMIT 后台下载 SSH 密钥

这是最简单的方式，适合刚入门的新手。

**第一步：进入 VPS 管理页面**

登录 DMIT 账号后，在首页找到"您目前可用的產品與服務"，点进去找到你的 VPS，点击"管理"进入详情页。

**第二步：找到 SSH 密钥下载入口**

在 VPS 管理页面里，找到 SSH 密钥相关选项。DMIT 会在这里提供一个下载按钮，点击下载，你会得到一个 `.pem` 格式的私钥文件。

> ⚠️ 这个文件只能下载一次，或者需要重置才能重新生成。下载之后务必保存好，建议备份到不止一个地方。丢了私钥就相当于失去了进入服务器的钥匙。

**第三步：修改文件权限（Linux/macOS 用户必须做）**

如果你用 Linux 或 macOS，SSH 客户端对私钥文件的权限非常敏感——权限太宽松会直接拒绝使用：

bash
chmod 600 ~/your-dmit-key.pem


Windows 用户不需要这一步，但需要在文件属性里设置只有自己能读取（后面的 PuTTY 和 XShell 章节会讲）。

**第四步：使用私钥连接**

有了私钥文件，就可以用各种客户端连接了。具体操作看下面的"客户端配置"章节。

## 方案 B：自己生成 SSH 密钥对

如果你想更高的控制感，或者已经在管理多台服务器，建议用这种方式。

### Windows 用户：用 PuTTYgen 生成

**第一步：打开 PuTTYgen**

如果你安装了 PuTTY，PuTTYgen 已经在里面了。直接搜索打开。

**第二步：生成密钥**

打开 PuTTYgen 后，默认是 RSA 2048 位。直接点 **Generate** 按钮，然后在空白区域随机晃动鼠标——这是在生成随机数，不是软件卡了，晃几秒就好。

**第三步：保存私钥**

生成完成后，点 **Save private key** 保存 `.ppk` 格式的私钥文件到本地。这就是你登录用的钥匙，保管好。

**第四步：复制公钥**

在 PuTTYgen 界面顶部有一个文本框，里面是 `ssh-rsa AAAA...` 开头的一长串文本，这就是你的**公钥**。全选复制。

**第五步：把公钥添加到 DMIT 账户**

登录 DMIT 后台，在账号设置或 SSH 密钥管理页面，把刚刚复制的公钥粘贴进去，保存。之后新开的 VPS 可以直接选这个密钥。

### macOS / Linux 用户：用终端一行命令搞定

bash
ssh-keygen -t ed25519 -C "your_email@example.com"


按照提示操作：
- 文件保存位置：直接回车用默认的 `~/.ssh/id_ed25519`
- 密码短语（passphrase）：可以设也可以不设。设了更安全，但每次登录要输入一次

生成完后，你的公钥在 `~/.ssh/id_ed25519.pub`，查看内容：

bash
cat ~/.ssh/id_ed25519.pub


把输出的内容（`ssh-ed25519 AAAA...` 开头的一行）复制，粘贴到 DMIT 后台的 SSH 密钥管理里。

> **为什么推荐 ed25519 而不是 RSA？** ed25519 是更现代的算法，密钥更短但安全性更高，生成和验证速度也更快。大多数现代 SSH 客户端都支持。

## 不同客户端的 SSH Key 配置教程

有了密钥之后，怎么用各种常见客户端连接 DMIT VPS？这里分别讲。

### XShell 配置密钥登录

XShell 是很多国内用户的首选 SSH 客户端，操作逻辑清晰。

1. 打开 XShell，新建会话（或编辑已有会话）
2. **连接** 选项卡：填入 DMIT VPS 的 IP 地址，端口默认 22
3. 切换到 **用户身份验证** 选项卡：
   - **方法**：选择 `Public Key`（公钥认证）
   - **用户名**：填 `root`
   - **用户密钥**：点击 **浏览** 或 **设置**，导入你的私钥文件
4. 如果是从 DMIT 下载的 `.pem` 文件，XShell 支持直接导入
5. 如果是 PuTTYgen 生成的 `.ppk` 文件，也直接支持
6. 保存会话，双击连接

第一次连接会提示"接受主机密钥"，点接受，正常的。

### PuTTY 配置密钥登录

PuTTY 是 Windows 上历史最悠久的 SSH 客户端，免费开源。

1. 打开 PuTTY，在 **Session** 里填入服务器 IP 和端口（22）
2. 左侧导航树找到 **Connection → SSH → Auth → Credentials**
3. 在 **Private key file for authentication** 里，浏览选择你的 `.ppk` 私钥文件
4. 回到 **Session**，点 **Save** 保存会话配置，然后 **Open** 连接
5. 首次连接接受主机密钥，登录用户名填 `root`，不需要输密码

> **如果你的私钥是 `.pem` 格式而不是 `.ppk`**：用 PuTTYgen 打开，点 **Load**，选择 `.pem` 文件，再 **Save private key** 另存为 `.ppk` 格式。

### macOS 终端直接连接

macOS 自带的终端就很好用，不需要额外安装软件。

**用 DMIT 下载的 .pem 文件：**

bash
ssh -i ~/Downloads/your-dmit-key.pem root@你的服务器IP


**用自己生成的密钥（默认路径）：**

bash
ssh root@你的服务器IP


如果密钥路径不是默认的，加 `-i` 指定：

bash
ssh -i ~/.ssh/my_custom_key root@你的服务器IP


**嫌每次打命令麻烦？配置 SSH config 文件：**

编辑 `~/.ssh/config`，加入：


Host dmit-vps
    HostName 你的服务器IP
    User root
    IdentityFile ~/.ssh/id_ed25519


以后直接 `ssh dmit-vps` 就能连，干净。

### Termius 配置密钥登录

Termius 是颜值派选手，iOS/Android/macOS/Windows 全平台，跨设备同步。

1. 在 Termius 里新建 Host，填入服务器 IP
2. 用户名填 `root`
3. **Password** 选项不填，改为展开 **Keys** 选项
4. 点击 **Add key**，选择导入已有密钥或生成新密钥
5. 如果导入，选择你的私钥文件（支持 `.pem`、`.ppk` 等格式）
6. 保存，点击 Host 直接连接

Termius 的优势是手机端也能用，出门在外用手机 SSH 进服务器处理紧急情况，体验比其他方案好不少。

## 常见问题：连不上？先看这几条

**Q：私钥文件权限不对，SSH 报错 "WARNING: UNPROTECTED PRIVATE KEY FILE!"**

这是 Linux/macOS 的安全机制，权限太宽松 SSH 会拒绝使用：

bash
chmod 600 /path/to/your/private_key.pem


**Q：连接超时，什么都连不上**

首先检查 DMIT 后台的防火墙/安全组设置，确保 22 端口（或你自定义的 SSH 端口）已开放入站流量。其次检查 VPS 是否正常运行。

**Q：提示 "Permission denied (publickey)"**

说明服务器上的公钥和你用的私钥不匹配。检查：
- 是否用了正确的私钥文件
- 登录用户名是否正确（通常是 `root`）
- 如果你自己上传的公钥，确认公钥格式正确，没有多余的换行或空格

**Q：PuTTY 报错 "Server refused our key"**

同上，公私钥不配对。另外注意：PuTTY 使用的是 `.ppk` 格式，如果你的是 `.pem` 文件，需要先用 PuTTYgen 转换。

**Q：macOS 每次都要输入密码短语（passphrase），很烦**

可以把私钥添加到 ssh-agent，只需输一次：

bash
ssh-add ~/.ssh/your_private_key


加 `-K` 参数（macOS Monterey 以下）或 `--apple-use-keychain`（Ventura 及以上）可以持久保存到 Keychain，重启后无需重新添加。
